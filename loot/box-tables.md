# Loot Box Tables

Roll a **d100** and read the column for the box's rarity. How many rolls a box gets depends on its rarity (see `loot-boxes`). A **Celestial** box does not use these columns. It contains the box type's **Celestial relic**, listed under each table (see `celestial-relics`).

**How to read the tables**

- *Italic names* are setting items. Find them in `explosives`, `firearms` or `dungeon-items`.
- Plain names are standard 5e magic items and gear.
- "×3" means three of that item. "Your choice" means the crawler who opens the box chooses.
- **Skill Book: X** teaches Crawler Skill X at Skill Level 1, or adds 1 Skill Level if the crawler already knows it (maximum 15).
