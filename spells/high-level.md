# 6th- to 9th-Level Spells

> *"These spells can end fights, floors and friendships. The System has disabled the 'Are you sure?' prompt for your convenience."*

Costs: **9 mana** for 6th level, **10** for 7th, **11** for 8th, **13** for 9th, at every rank. You can still cast only **one spell of each level from 6th to 9th** per long rest with mana (see `mana`). Ranks make these spells better, not cheaper. Each rank includes everything from the ranks below it unless it says otherwise.
