# Rogue — World Dungeon Changes

Everything here changes or adds to the rogue as the Player's Handbook describes it. Where this page and the class text disagree, this page wins. Add new rogue changes here; the Rogue Codex is built from it.

## Changes

- **Sneak Attack** stacks with the *Backstab* Crawler Skill.
- **Expertise** stacks with Crawler Skills that give advantage, but not with other Expertise.
- **Arcane Trickster** is a third caster: you learn spells from the World Dungeon **Wizard** list, up to 4th level (see *Spells* at the end of this codex), and you gain one **Rank Up** for each Rogue level from 3rd on. Mage Hand Legerdemain uses *Grabby Hand* (for *mage hand*).
- **Thief: Use Magic Device** works on System items and celestial relics, if the GM agrees.
- **Thieves' Cant** works between crawlers, and most dungeon NPCs pretend not to understand it.
- **Sticky Fingers** and *Lock and Key* are the Crawler Skills rogues reach for first.
