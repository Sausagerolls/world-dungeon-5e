# Fighter — World Dungeon Changes

Everything here changes or adds to the fighter as the Player's Handbook describes it. Where this page and the class text disagree, this page wins. Add new fighter changes here; the Fighter Codex is built from it.

## Changes

- **Extra Attack** overlaps the survivor feature if you have it (see `crawler`). Two Extra Attacks and Three Extra Attacks replace it.
- **Weapon Mastery** uses your Crawler weapon proficiencies too, and stacks with *Weapon Specialist*.
- **Fighting Style** feats work as normal. The *Bodyguard* Crawler Skill pairs well with Protection and Interception.
- **Eldritch Knight** is a third caster: you learn spells from the World Dungeon **Wizard** list, up to 4th level (see *Spells* at the end of this codex), and you gain one **Rank Up** for each Fighter level from 3rd on. War Magic and Eldritch Strike work with World Dungeon cantrips and spells.
- **Battle Master** manoeuvres work as normal. Superiority Dice are not mana.
- **Psi Warrior** psionic energy dice are not mana either.
