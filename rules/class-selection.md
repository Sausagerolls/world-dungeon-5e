# Floor 3 Class Selection

> *"Congratulations on surviving two whole floors! Please select a class from the menu. All sales are final. No, you cannot speak to a manager."*

On arrival at Floor 3, the System opens the **Race and Class selection** menu. Each crawler must choose a race and a class before they leave the first safe room on the floor.

## Choosing a Class

**You can pick any class from the core Player's Handbook.** Your table uses one edition of the Player's Handbook (2014 or 2024); use its classes and subclasses.

- **Subclass.** You gain your subclass at the class's normal level, from the Player's Handbook options (or others your GM allows).
- **The System's pitch.** The System "recommends" a class based on your Inclination, Crawler Skills and behavior so far. It is only a sales pitch. You can ignore it.
- **No class.** You can refuse to pick a class and stay a plain Crawler. The System warns you that this is a bad idea, and it is: you keep Crawler Core and survivor features, but never gain class features. *(GM: for very brave players only.)*

**Spellcasting uses mana.** Every spellcasting class casts with mana instead of spell slots. Work out your class mana from your caster level, and warlocks their Pact Mana (see `mana`). Your class does not keep its own spell list. Whenever it would let you learn or prepare a spell, you learn a **tome spell** from its World Dungeon spell list instead (see `spell-lists`), and you never prepare spells (see `tome-magic`). Spells your class or subclass grants by name become their World Dungeon replacements (see `spells-replacements`).

### Race

You also choose a race (or species) on Floor 3, from the 2024 Player's Handbook species and any others your GM allows. Until then a crawler has no race, even one who was human before the collapse. The rules, the System's pitches and the choices each race asks for are in `race-selection`.

## Procedure

Let **N** be the crawler's character level. Expect N to be about 7–9 (see `leveling`).

1. **Keep everything Crawler.** The crawler keeps all of Crawler Core (The Interface, Crawler Inventory, all Stat Points spent and saved, all Crawler Skills and their Skill Levels, Tome Learning and all tome spells, Heal Self, achievements and loot) and all **survivor features** (Scrappy, Will to Live, Run Away!, Inclination, Hard to Kill, Hardened and Danger Sense).
2. **Gain the class at level N.** The crawler becomes an N-level character of the chosen class. They gain every class feature from 1st level to level N, including their subclass if N is high enough, and class Ability Score Improvements or feats at the usual class levels.
3. **Check overlaps.** Where a survivor feature overlaps a class feature (Extra Attack, duplicate proficiencies), follow the overlap rules in `crawler`.
4. **Keep base proficiencies.** The crawler keeps Crawler armor, weapon, tool and skill proficiencies, every proficiency learned through *Learning by Doing*, plus the "ordinary person" skill and language.
5. **Replace saving throws.** The crawler's saving throw proficiencies become the class's saving throws.
6. **Add class proficiencies.** The crawler gains the class's 1st-level armor, weapon, tool and skill proficiencies.
7. **Keep your hit points.** Do not recalculate. Your levels so far keep their d8 Hit Dice and hit points. From your next level on, each level gives the hit die of the class you take it in (see *Hit Points and Hit Dice* in `crawler`).
8. **Work out mana and learn spells.** A spellcasting class adds class mana (or Pact Mana) to the crawler's mana pool (see `mana`). Learn as many cantrips and spells from the class's World Dungeon list as its table gives at class level N, add the replacements of any spells the class or subclass grants, and write them into your tome as tome spells (see `tome-magic`). Then spend one **Rank Up** for each class level that teaches spells (see *Spell Ranks* in `tome-magic`).
9. **Apply race.** Gain the chosen race's traits and make its choices (see `race-selection`).
10. **Class starter box.** The System gives one Bronze **Class Box** with gear for the new class. Roll on the Class Box table in `box-tables`.

## After Class Selection

- **One level at a time.** Each new character level is one level in one class: your class, or a new one through multiclassing. It gives that class's hit die, and also advances Crawler Core (1 Stat Point every level, a Skill Pick every 5th level).
- **Multiclassing** uses the normal 5e rules, based on class levels only, with any Player's Handbook class. Crawler is not a class for multiclass purposes, and Crawler Core features always use total character level. Caster levels from different classes add together for class mana.
- No class goes above 20th level. After 20th, levels in that class become **prestige levels** (see `prestige-levels`), or you can multiclass.

## GM Notes

- Hold the selection in the first safe room on Floor 3, so players have time to choose. It is a good roleplay scene: the System pitches each class like a game show host. Read the pitches from the table above.
- If a player is unsure, point them at the class that fits their Inclination and Crawler Skills.
- Characters arrive at Floor 3 at about level 23, so they gain a whole class at once. Give the table time to read it, or do the selection between sessions.
- **More than 20 levels.** No class goes above 20th level, so a crawler with more than 20 levels puts 20 into their chosen class. The rest become prestige levels in that class (see `prestige-levels`) or levels in a second class (multiclassing prerequisites apply). Each prestige level and second-class level gives its own features, as if gained one at a time.
